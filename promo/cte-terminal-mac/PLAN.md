# Catch the Error: terminal-mac, a whole Mac inside a terminal, for your AI agent

**What it's for:** a Reel / Short (1080×1920, 79 s of voice + the ident, 87 s) on govijr/terminal-mac
(github.com/govijr/terminal-mac, v0.2.0 build 6, Nov 3, 2026), made like a paid launch ad (the owner: "present it like
we're getting paid around 10k dollars to advertise"), with ~13 s of the project's own launch footage.
**Who it's for:** people who use coding agents (Claude Code, Cursor, Codex) and have seen "computer use" take over a
desktop.
**One question:** what if the agent had its own Mac and left yours alone?

**Format:** the launch ad with a catch: hook → pain → product → proof (real footage) → how it works (dots, bars) →
reach (tools, clients, one line) → *what's the catch?* (the fine print) → payoff (callback) → one-word ask.
**World:** *the desktop*, new for this video (the last two were the exam paper and the paper neural network): a warm
sand desk where everything is a window. Matte terminal windows, drawn screens on stands, two cursors as the cast
(yours in ink, the agent's in red), the real footage as rounded cards the camera moves inside. Dark "inside the
machine" scenes for the mechanism (helper, frames, bars). Geist for statements, serif italic for the idea word, Mono
for everything a terminal would say. The red pen still rings, strikes and ticks.
**Anchor image:** the Droste: the real frame of macOS running inside the terminal, with the same frame inside its own
desktop, and again, and again. It's the cover and the last scene (the ask).
**Unique thing:** the agent's red cursor is a character: it flies into the footage on "AI agent", takes your mouse
and clicks the wrong button on "your click", then hops on an arc to its own Mac on "its own Mac".

## Retention plan (research, 2026-11-04)
Directional, from practitioner blogs (no platform publishes these weights; trust our own analytics):
- **First 3 s:** real footage already playing on frame 1 (terminal-mac being typed), the headline already on screen,
  the voice at 0.05 s; macOS boots inside the terminal on the word "Mac" with the one sub hit. A contradiction ("a
  whole Mac inside a terminal") and a turn at 3 s ("it's not for you").
- **Open loops, nested:** "it's for your AI agent" (why?) → the pain answers it → "Watch." promises proof → "Here's
  the clever part" re-opens at 34 s (the re-hook, with the second drop of the music) → "So, what's the catch?" at
  57 s holds people through the fine print.
- **Pattern interrupts:** a cut or a new element every 1-3 s on spoken words; the mode changes about every 10 s
  (footage → drawn desk → dots → footage → dark mechanism → bars → network → ink catch → fine print → Droste).
- **Show, don't list:** one concrete use case (Claude drawing a diagram in Freeform, real, 16×), one specific
  benefit (your pointer is untouched), one honest catch, one soft ask.
- **Muted viewers:** every line is on screen at the top as it's said (the topcap), so the video reads with the sound
  off.
- **Comments as a surface:** a binary question ("would you let an agent drive your Mac? yes or no").

## Facts and sources (checked 2026-11-04)
- README (github.com/govijr/terminal-mac, commit 7009117, "Release 0.2.0 build 6", Nov 3, 2026): Apple
  Virtualization runs a real macOS guest; a helper inside the guest captures its screen and posts input; agent
  commands don't move the physical pointer or change the clipboard; MCP tools screenshot, click, drag, scroll, type,
  key, status; Claude Code plugin `/plugin install terminal-mac --marketplace govijr/terminal-mac`; other MCP clients
  (Cursor, VS Code, Codex, Windsurf) via `terminal-mac mcp --config`; the curl installer verifies SHA-256 and needs no
  admin rights; a frame only when the screen changes (up to 30 fps), lossless lz4, sized to the terminal; the stream
  stops 15 s after the viewer leaves; two shares (control read/write, tools read-only), host home, project folders,
  clipboard, microphone and camera not attached; default NAT networking, "not a network-isolated or hardened
  hostile-code environment", `--offline` removes that path; internet on first run to download macOS from Apple;
  64 GiB logical disk, sparse; Apple silicon, macOS 14+; "early release candidate"; "self-signed (no Apple
  notarization)". LICENSE: MIT.
- The footage: @kirtandopamine on X, "Introducing terminal-mac…" (x.com/kirtandopamine/status/2117678349828976746)
  and "this is a demo of claude using terminal-mac" (…/2117678355440914786). The About window in it reads "Apple
  Virtual Machine 1", "Apple M4 Pro (Virtual)". The demo's prompt: "Open Freeform on my virtual Mac and draw a simple
  diagram: Claude Code → terminal-mac → macOS VM". Shown sped up 16× and labelled.
- Labelled as illustrations on screen: the dot timeline (which frames get sent), the bar chart (a fixed 30 fps stream
  vs terminal-mac), the download progress.
- Not claimed: star counts, speed numbers, compressed sizes, anything about security beyond the README's words.
